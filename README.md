# Personal Portfolio Website

A professional portfolio website built with Django to showcase my projects, technical skills, academic background, certifications, and professional experience.

The website includes a project portfolio, resume section, contact form, RSS feed, blog functionality, and a responsive user interface. It is deployed on a Linux VPS and designed to demonstrate modern Django development practices.

## Live Demo

🌐 Website: https://afsanehhassani.com

## Features

* Responsive and modern user interface
* Professional portfolio and project showcase
* Resume and educational background section
* Certificates and achievements section
* Contact form with email integration
* Blog system
* RSS feed support
* Dynamic content management through Django Admin
* PostgreSQL database integration
* VPS deployment
* Docker support
* SEO-friendly structure

## Installation

Clone the repository:

```bash
git clone https://github.com/Afsaneh-hassani/portfolio-afsaneh.git
cd portfolio-afsaneh
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate virtual environment:

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Apply migrations:

```bash
python manage.py migrate
```

Create superuser:

```bash
python manage.py createsuperuser
```

Run development server:

```bash
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```
